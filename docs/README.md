- [Data model](data-model.md) — what the module reads from `/alerts` and `/regions`, the node_helper routes and headers, internal caches
- [Development](development.md) — running the tests, project layout, common changes, releases
- [History](history/) — design documents and plans of past features (full-alert threshold, relay mode); kept for context, the code is the source of truth
